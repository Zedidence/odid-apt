# odid-apt

Signed apt repository for [ODID Sniffer](https://github.com/Zedidence/ODID_Sniffer),
a Remote ID (OpenDroneID) sensor for Raspberry Pi OS / Debian 13 (trixie).

Install on a Pi:

```
curl -fsSL https://zedidence.github.io/odid-apt/get-odid.sh | \
    sudo ODID_APT_REPO=https://zedidence.github.io/odid-apt \
         ODID_KEY_FPR=BCD167E85F4D48EE321BEF88C88AAAC93B5F5030 bash
```
